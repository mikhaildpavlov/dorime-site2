# DorimЭ — Voiceover Studio

Static bilingual site for DorimЭ.

- English is the default language.
- EN / RU switcher is built into the header and remembers the visitor's choice.
- No build step is required: open `index.html` locally or publish the folder with Cloudflare Pages / GitHub Pages.
- Replace placeholder portfolio cards with real MP4/MOV files in `assets/` when ready.
- Update Telegram, socials and other contact details in `script.js`.

## Cloudflare Pages
Build command: `exit 0`
Output directory: `/`
Framework: none / static HTML
